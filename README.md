# Low-Cost Spectrophotometer

### Arduino-Based Optical Measurement and Spectrophotometer Prototype

An academic hardware project exploring an affordable spectrophotometer implementation using Arduino-based electronics and optical sensing.

---

## 📌 Project Overview

The Low-Cost Spectrophotometer was developed as part of the Physics of Semiconductor Devices course.

The project explores the development of an affordable optical measurement system using an Arduino UNO and associated electronic hardware.

The work involved circuit planning, software planning and hardware construction.

The prototype was presented as part of the academic project demonstration.

## 🎯 Objectives

- Explore the working principles of spectrophotometry.
- Develop a low-cost optical measurement prototype.
- Integrate Arduino-based electronics with sensing hardware.
- Understand the relationship between optical sensing and electronic measurement.
- Apply semiconductor device and instrumentation concepts.

## 🔬 Working Principle

Spectrophotometry involves analysing the interaction of light with a material.

A typical spectrophotometer measures light intensity before and after interaction with a sample to study its optical properties.

This project explores an Arduino-based implementation of optical measurement.
